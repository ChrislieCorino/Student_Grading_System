# Student_Grading_System
A simple grading system built in the command line

# Description
The student grading system is a system that allows a student to check their grades, totals, averages and gives a status reading.

All data is stored in memory and will reset when the program is closed.

# Features
Enter name - Enter student name
Exam - Enter 5 exam marks

# Requirements
Python 3.6 or higher
No external libraries needed. Uses only built-in Python

# How to Run
Make sure you have Python installed
Download/save the file as banking_system.py
Open terminal in the folder and run
Follow the on-screen instruction

# Rules
Only enter required marks and nothing else

# Future Improvements
Allow for students to enter more than 5 marks
